# v0.2.0: lazy stages and durable evidence

Preparation stops paying for unrequested whole-video decoding. Transcription, overview, change scanning, and global frame indexing become separate stages; nearby frame requests share a bounded decode.

- Verify decoded timestamps and actual frame identity across variable frame rates, duplicate timestamps, delayed streams, rotation, and anamorphic video.
- Default FFmpeg pools use two threads; sheet geometry and hashing memory are bounded. Speaker analysis becomes explicit, and cached results avoid provider work.
- Retain authored notes, complete transcripts, and selected packet dependencies in verified snapshots. Cleanup previews first, then moves eligible analysis to native Trash.

All measurements were made on a **MacBook Pro M5 Pro**. Timings are serial command execution, excluding agent work and separate correctness checks. Caches were not cleared. CPU includes waited child processes; peak RSS is an individual-process high-water mark, not aggregate memory. Heat, energy, and UI responsiveness were not measured.

## Controlled comparison with v0.1.0

Medians of two fresh-analysis runs on the same synthetic sources, using authored text or no speech rather than speech inference. The requested sequence is preparation, late still, native-frame range, sampled range, overview, and change scan. Warm calls and global indexing are excluded. Scheduling and overview sampling differ, so total internal work is not identical.

| Fixture | Prepare, 0.1 -> 0.2 | Prepare RSS, 0.1 -> 0.2 | Sequence, 0.1 -> 0.2 | Sequence CPU, 0.1 -> 0.2 |
|---|---:|---:|---:|---:|
| Slides, 24 s | 0.729 -> 0.131 s | 114 -> 18 MiB | 1.108 -> 1.019 s | 1.515 -> 0.933 s |
| Motion, 18 s / 60 fps | 1.881 -> 0.118 s | 189 -> 21 MiB | 2.339 -> 2.462 s | 5.720 -> 3.866 s |
| Motion, 120 s | 3.259 -> 0.129 s | 149 -> 18 MiB | 3.717 -> 3.258 s | 8.899 -> 4.467 s |
| Variable frame rate, 12 s | 0.982 -> 0.082 s | 118 -> 21 MiB | failed -> 1.334 s | failed -> 1.536 s |
| Nonzero timestamps, 12 s | 0.840 -> 0.112 s | 118 -> 20 MiB | 1.260 -> 1.254 s | 2.138 -> 1.323 s |
| Rotation, 18 s | 2.400 -> 0.121 s | 218 -> 21 MiB | 3.129 -> 3.044 s | 10.697 -> 7.874 s |

Preparation was **5.5-25x faster**. Completed comparable sequences used **26-50% less CPU**; wall time improved 0.4-12% on four fixtures but was **5.3% slower** on high-rate motion. Sequence peak RSS fell from 124-250 to 50-90 MiB. Warm inspections took 25-26 ms.

Global indexing is deferred, not eliminated: first global-frame requests took 0.33-1.24 s versus roughly 0.09-0.14 s on most already-indexed baseline analyses. The final matrix passed **204/204 operations and 144 packet validations**.

## Real-media checks

On one 30-second speech clip, median workflow time fell from **4.057 s to 0.976 s** with the new default, or **1.083 s with speaker analysis enabled**. Two runs per configuration returned identical text and word timings when speaker labels were ignored. The old workflow also performed eager visuals; runtime caches were warm. This does not isolate speech-engine performance or recognition accuracy.

A separate **59:45 PDF walkthrough, 1080p30 H.264**, established these absolute v0.2 results:

| Operation | Command time |
|---|---:|
| Complete local transcription | 13.204 s |
| Twelve-image overview | 1.922 s |
| Three short sampled ranges | 0.452 / 0.550 / 0.616 s |
| Linked detail still | 0.168 s |
| Optional whole-video change scan | 66.875 s |
| Cached transcript / visual requests | 25-40 ms |

Preparation, transcription, overview, three ranges, and detail totaled **18.007 s after acquisition**. Transcription peaked at 435.9 MiB; change scanning at 255.0 MiB. This single-source run has no v0.1 baseline. Acquisition and agent reading are additional.

All 30 long-video commands succeeded. The complete 65,526-byte transcript was read; 47 distinct visual timestamps were inspected. After cleanup, 71 retained files and seven note links verified, and the source was unchanged. Sampling does not establish exhaustive visual coverage or transcript accuracy.

The release suite recorded **132 passed tests, one optional skip, zero failures**.
