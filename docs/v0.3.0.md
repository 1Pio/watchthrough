# v0.3.0: native acquisition and clearer evidence

This release addresses friction observed in v0.2's real-video workflow.

| Change from v0.2 | Result |
|---|---|
| Agent-written YouTube acquisition | Native `acquire` returns an owned, resumable local source bundle with compact provenance. Current formats preserve the selected resolution, native frame rate, and audio-language priority; merging copies streams. |
| Manual downloader maintenance | Explicit managed setup verifies the official release before activation. Completed sources reuse without network access or downloader startup; failed updates preserve the working package. |
| Long interval captions appeared contemporaneous with frames | Sheets show separately timed nearby speech, silence, and visible truncation. Packets retain complete interval text. |
| Verification could miss ordinary inspection packets | `status --verify` checks every completed owned packet. Reuse filters by evidence identity before hashing matching candidates. |
| Returned paths needed rewriting before retention | `retain --include` accepts returned absolute packet paths inside the analysis and preserves their dependencies. |

All measurements were made on a **MacBook Pro M5 Pro**. Each listed operation ran once unless marked cached. Timings exclude agent work; caches were not cleared. CPU includes waited child processes, and peak RSS is the highest individual-process peak, not total concurrent memory. No heat, energy, or UI-responsiveness measurement was made.

## Measured complete workflow

Source: [WeatherNext 3](https://www.youtube.com/watch?v=_6jZlnRsXXQ), **4:35, 1920x1080 at 25 fps, AV1 plus original English Opus, 42.2 MB**. Selected streams, native rate, duration, and end packets were validated.

| Operation | Command time | Evidence |
|---|---:|---|
| Fresh acquisition, including managed setup | 11.022 s | Complete local source; copy-only merge |
| Retry an earlier incomplete bundle | 4.014 s | Accepted completed media after metadata-framing failure; no new media transfer |
| Cached acquisition after preparation | 0.026 s | Succeeded with downloader deliberately unavailable |
| Default preparation and full local transcription | 14.838 s | Entire 5,637-byte word-timed transcript read |
| Twelve-image overview | 1.992 s | All samples opened, including the decoded tail |
| Two one-second native-frame probes | 0.296 / 0.249 s | Each returned 26 distinct frames, 0.04 s apart; both inspected |
| Detail still | 0.176 s | Native-resolution labels inspected |
| PNG relayout | 0.205 s | Ordered frame hashes unchanged; four sheets rendered |
| Cached overview / motion | 0.032 / 0.027 s | Existing packets reused |
| Optional whole-video change scan | 8.985 s | 32 routing candidates |
| Explicit verification | 0.062 s | All five completed packets verified |
| Retain / cleanup preview / native Trash | 0.773 / 0.580 / 0.349 s | Durable evidence reopened after cleanup |

The primary sequence totaled **30.542 s**, including acquisition, preparation/transcription, overview, both probes, detail, relayout, verification, retention, and cleanup. Diagnostic retry, cached calls, and the optional event scan are additional.

Preparation/transcription peaked at **2.72 GiB RSS**; visual commands peaked at **101.2 MiB**. These are single-run observations, not a matched v0.2 comparison. Different source lengths, codecs, and runtime state prevent interpreting differences from the earlier hour-video result as a version speedup.

## Acceptance and limits

All **16 listed operations succeeded**. The test suite recorded **182 tests, one optional skip, zero failures**; the packaged installer test also passed. Tests cover false-success downloads, malformed completion records, partial-fragment resume, corrupt packets, unsafe paths, and update rollback.

After native Trash cleanup, **116 retained files (11.95 MB), 11 note links, and the complete transcript verified**. The source was unchanged and a retained image reopened. Existing v0.2 analyses remain readable.

The live retry recovered completed media awaiting validation; partial network-transfer resume was tested with controlled fixtures. Event candidates were counted, not individually inspected. Full transcript reading and selected images establish usable evidence, not recognition accuracy, complete visual coverage, or future upstream download reliability.
